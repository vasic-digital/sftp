# sftp

Enterprise SFTP service with full account management — Go/Gin REST API, YAML/JSON
configuration, super-admin authentication, Web (React/TS) + cross-platform mobile
(KMP: Android / iOS / HarmonyOS / AuroraOS) admin clients, rootless-Podman
operations, and a complete anti-bluff QA regime (Helix Constitution governed).

> **Status:** enterprise build-out in progress — see `docs/CONTINUATION.md` and
> `docs/plans/master_implementation_plan.md`. The original basic atmoz/sftp
> deployment guide is preserved at `docs/research/mvp/MVP.md`.

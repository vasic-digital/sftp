SFTP Enterprise Management API

Version 0.1.0-dev — OpenAPI 3.0.3

REST API for managing SFTP accounts, authentication, and user configuration synchronization. This API is the control plane for the SFTP Enterprise system backed by `atmoz/sftp` running under rootless Podman.

Accounts

GET /accounts Bearer token
List all SFTP accounts
Returns all accounts without any password material.
200 Account list. → AccountListResponse
401 Missing or invalid access token.
POST /accounts Bearer token
Create a new SFTP account
Creates an SFTP account with a bcrypt-hashed password and a sha512-crypt hash stored in the encrypted vault for users.conf rendering. `public` permission requires `public_acknowledged: true`.
Body: AccountRequest
201 Account created. → AccountResponse
400 Missing fields or invalid values. → ErrorResponse
401 Missing or invalid access token.
409 Username already exists. → ErrorResponse
422 Public permission set without `public_acknowledged: true`. The error message is explicit: "public access is never a default: set public_acknowledged=true to confirm". → ErrorResponse
GET /accounts/{username} Bearer token
Get a single account
200 Account found. → AccountResponse
401 Missing or invalid access token.
404 Account not found. → ErrorResponse
PUT /accounts/{username} Bearer token
Update an existing account
Replaces mutable fields. Password is optional: when provided it is re-hashed; when omitted the existing hash is kept. The username in the path wins over any username in the body.
Body: AccountRequest
200 Account updated. → AccountResponse
400 Missing fields or invalid values.
401 Missing or invalid access token.
404 Account not found.
422 Public permission set without acknowledgement.
DELETE /accounts/{username} Bearer token
Delete an account
Removes the account from the database and the encrypted vault. The vault entry deletion is best-effort (errors are silently ignored after the DB record is gone).
204 Account deleted (no content).
401 Missing or invalid access token.
404 Account not found. → ErrorResponse

Auth

POST /auth/login
Authenticate super-admin
Validates the super-admin credentials and returns a JWT access token + refresh token pair. The refresh token is also set as an HttpOnly, SameSite=Strict cookie. Rate-limited by client IP (default 10 req/min, configurable).
Body: LoginRequest
200 Authentication successful. → TokenResponse
400 Missing fields or invalid JSON. → ErrorResponse
401 Invalid username or password (no user enumeration). → ErrorResponse
429 Rate limit exceeded. → ErrorResponse
POST /auth/refresh
Refresh JWT token pair
Exchanges a valid refresh token (read from HttpOnly cookie first, then JSON body as fallback) for a new access + refresh token pair. Rate-limited by client IP.
Body: RefreshRequest
200 New token pair issued. → TokenResponse
400 Missing refresh token. → ErrorResponse
401 Invalid or expired refresh token. → ErrorResponse
429 Rate limit exceeded.
GET /auth/me Bearer token
Get current user identity
Returns the username and token expiry from the active access token.
200 Caller identity. → MeResponse
401 Missing or invalid access token. → ErrorResponse
POST /auth/logout Bearer token
Revoke refresh token
Revokes the provided refresh token and clears the HttpOnly cookie. The token is read from the cookie first, then the JSON body as fallback.
Body: LogoutRequest
200 Token revoked, cookie cleared. → LogoutResponse
400 Missing refresh token. → ErrorResponse
401 Invalid or expired refresh token / missing access token. → ErrorResponse

Health

GET /health
Liveness probe
Returns the API version, current time, and Firebase status.
200 API is healthy. → HealthResponse

Sync

POST /sync Bearer token
Render users.conf
Reads all accounts from the database and renders `users.conf` in the atmoz/sftp format. The rendered file path is returned in the response.
200 users.conf rendered. → SyncResponse
401 Missing or invalid access token.
